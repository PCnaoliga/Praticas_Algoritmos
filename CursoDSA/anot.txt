##BIG O NOTATION##
- Fala sobre escalabilidade, não necessariamente sobre performace
  > É dividido em complexidade temporal e espacial
  > Complexidade temporal: É o quanto o algoritmo escala seu tempo
    em relação ao seu input de dados
  > Complexidade espacial: É o quando o seu algoritmo usa de dados
    na memoria para ser rodado

- O(1):
  > É em tese a notação mais rapida, onde o TEMPO de execução dele 
    é linear em relação a quantida de input do algoritmo.
  > Sua complexidade espacial é fixa.




##Linked List##
- São as lintas linkadas, listas que possuem ponteiros de referencias
  dos proximos elementos e do elemento do inicio e fim
- NOTAÇÃO BIG 0 NAS LINKED LIST:
  > Read: Melhor:O(1); Pior:O(n)
  > Insert: Melhor:O(1); Pior:O(n)
  > Delete: Melhor:O(1); Pior:O(n)

##Queue ou Fila##
- É uma estrutura que é igual a linked list, seguindo a logica do 
  primeiro a entrar é o ultimo a sair.
- Uma Dqueue é uma fila com orientações do ponteiro apontando para
  frente e para o elemento anterior.

##Hashmap##
- Sua complexidade e O(1)
- Pode ser usado com qualquer estrutura de dados
- Funciona com um valor principal e o segundo valor q vai determinar
  primeiro.Ex.:["Pc","Beta"], o valor "Pc" tem a chave "Beta"
- De maneira simples e sempre usar um valor para identificar o local 
  no ARRAY que determinado valor estar.

##Grafos##
- É uma estrutura de dados, onde os modulos estão linkados entre si
  de forma, e cada link pode haver pesos, onde a depender do problema
  esse pesos vão influenciar a forma de movimentações desses grafos.

##Trie ou prefix-tree##
- É um tipo de arvores, onde a cada vez que vamos descer a arvore vai
  deixar um prefixo, o exemplo mais famoso é os autocomplite.

##B-Tree##
- É um arvores autobalanciavel que vai seguir regras
- Essas regras são:
  > Definir o numero de chaves e de Keys
  > O numero de childrens(modulos abaixo na arvore) vai ser sempre
    um a mais que os de keys
